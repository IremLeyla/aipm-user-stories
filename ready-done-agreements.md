# Ready and Done Agreements

Draft proposal for the team to agree. Keep it minimal and revisit after the first pilot week.

## Definition of Ready (Backlog → Ready)

A story can move to **Ready** when:

1. Role, goal and benefit are clear, and the role is a real pilot role.
2. Acceptance criteria are written and testable.
3. Dependencies are known, and any blocking decision task is done.
4. Open questions and ⚠️ assumptions are visible on the issue.
5. The story fits within one pilot week.
6. The PM has approved the story. This matters most for agent-proposed stories.

Discovery work (decision tasks such as DT-01 and DT-02) can start without meeting all six points.

## Definition of Done (Review → Done)

A story can move to **Done** when:

1. All acceptance criteria are met and shown to the PM.
2. Only approved policy documents are used.
3. Fallback behaviour ("not covered", errors) is tested.
4. Outputs are checked against a set of agreed example questions.
5. The human review path works where the story touches flagged answers.
6. User-facing wording is reviewed, by legal where it involves disclaimers.
7. Known limitations are written on the issue.
8. Evaluation results are labelled as pilot, mock or validated.

## Board columns

| Column | Meaning |
|---|---|
| Backlog | Captured, not yet refined |
| Ready | Meets the Definition of Ready |
| In progress | Being worked on |
| Review | Waiting for a Definition of Done check |
| Blocked | Waiting on a decision, dependency or person. Write what it's waiting for. |
| Done | Meets the Definition of Done |
